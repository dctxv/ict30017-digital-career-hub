## 1. The upload page had been silently reverted

The Playwright suite had 9 failures out of 20, all on the resume review page.
The specs targeted `.drop`, `.rr-file-error`, `.rr-quota` and `.rr-choice`;
the page had none of them.

The cause was the localisation commit of 13 September (`054842d`). It
replaced `ResumeReview.jsx` and its stylesheet with the pre-rework version of
the page and added the language prompt on top. That brought back:

- `--green-700` and `--green-200`, colours the theme no longer declares. An
  undefined variable resolves to nothing, so the drop-zone icon and the
  analysing spinner's ring rendered invisible. Lint and the build were clean.
- A private set of `.btn-primary` / `.btn-outline` classes beside the shared
  `.btn--*` ones, and a second inline copy of the sample review that
  `data/sampleReview.js` already held.
- The `marketMode` prop dropped from `ResultsView`, so every results header
  said "Bangladesh employers" whatever had been chosen.

Restored from the parent of that commit, with the two things the commit
genuinely added re-applied: the language prompt before the first Analyse
click (the chosen language is passed straight to the stream rather than read
back from state in the same tick), and the sample being chosen at render so
the EN/BN toggle works while it is on screen. The specs now answer the prompt.

**The lesson is the one from section 5 of `ui_rework_as_built.md`, repeated
because it happened again:** an undefined CSS variable fails silently. There is
now a unit test (`client/src/styles/tokens.test.js`) that fails the suite on
any `var(--x)` the theme does not declare, and on any colour token the light
theme declares that the dark theme does not. `npm test` in `client/` runs it.

## 2. Every page scrolled sideways on a phone

At 390px the navbar's three controls ended 6px past the right edge on every
page, because the wordmark would not shrink. Under 600px it now steps down a
point, the language switch takes its compact width, and the wordmark
truncates before the controls move. On Career Paths the "Find related
resources for {title}" button inherited `.btn`'s one-line rule and ran to
415px; it wraps. Measured at 390px on every public page, the account area and
the preparation page: none scrolls.

## 3. Journey gaps

- **Guests were sent to an empty plan.** "Build my preparation plan" showed
  for everyone, but a guest's review is never saved and produces no gaps, so
  the link went through the login form to an empty board. Guests now see
  "Sign up to keep this review and build a plan", and the register page
  honours a redirect target the way the login page already did.
- **Interview answers were lost on reload.** Five typed answers lived only in
  React state, and the server stores them only when an assessment fails.
  Drafts are now mirrored to the device per interview id, restored from Past
  Interviews, and cleared once the assessment has returned.
- **Analyse stayed enabled at zero allowance**, letting the click reach the
  server to be refused. Disabled for a signed-in user whose count is spent.
- **Two figures skipped Bengali numerals**: the headline "/100" and the
  open-gap badge on the Preparation tab.

pre-installed Chromium: the project's Playwright version wants its own
browser build. Point it at the installed one with a local config that sets
`launchOptions.executablePath`, rather than downloading.
